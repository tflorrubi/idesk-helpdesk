

## Descripción

IDESK es una plataforma de mesa de ayuda que permite registrar, administrar y dar seguimiento a tickets de soporte técnico. El sistema busca facilitar la atención de incidencias y mejorar el control de las solicitudes.

## Funcionalidades

- Registro de usuarios
- Inicio de sesión y autenticación
- Creación de tickets
- Consulta y seguimiento de tickets
- Asignación de tickets a técnicos
- Gestión de estados
- Clasificación de prioridades
- Dashboard administrativo
- Chatbot de soporte
- Cierre de tickets

## Tecnologías

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## Proyecto

Proyecto académico desarrollado como sistema web de mesa de ayuda.
